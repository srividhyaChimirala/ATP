# JavaScript Movie Collection Analyzer

This program demonstrates the use of important JavaScript array methods such as:

- `filter()`
- `map()`
- `reduce()`
- `find()`
- `findIndex()`

using a movie collection example.

---

## Description

The program performs the following operations:

- Displays all movie records
- Filters only Sci-Fi movies
- Maps movie titles with ratings
- Calculates average movie rating
- Finds movie named `"Joker"`
- Finds index of movie `"Avengers"`

This example helps understand array manipulation techniques in JavaScript.

## Variables Used

| Variable Name         | Description                            |
|------------------------|----------------------------------------|
| `movies`               | Stores movie records                   |
| `sciFiMovies`          | Stores only Sci-Fi movies              |
| `movieRatings`         | Stores movie titles with ratings       |
| `totalRatings`         | Stores sum of all movie ratings        |
| `averageMovieRating`   | Stores average movie rating            |
| `jokerMovie`           | Stores details of movie `"Joker"`      |
| `avengersMovieIndex`   | Stores index of movie `"Avengers"`     |
