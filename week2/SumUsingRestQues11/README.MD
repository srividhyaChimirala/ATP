# JavaScript REST Parameter Sum Function

## Description

This project demonstrates how to use REST parameters in JavaScript to receive multiple arguments and calculate their sum.

The program:
- Accepts any number of arguments
- Uses REST parameters (`...`)
- Calculates the sum using:
  - Loop method
  - `reduce()` method
- Displays the final result
