# JavaScript Object Copying using Spread Operator

## Description

This project demonstrates how to copy and update objects using the JavaScript spread operator (`...`).

The program:
- Creates a user object
- Copies all properties using the spread operator
- Adds a new property (`age`)
- Displays both objects

The original object remains unchanged.
