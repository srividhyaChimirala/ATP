# JavaScript Banking Transactions Analyzer

This program demonstrates the use of important JavaScript array methods such as:

- `filter()`
- `map()`
- `reduce()`
- `find()`
- `findIndex()`

using a banking transactions example.

---

## Description

The program performs the following operations:

- Displays all transactions
- Filters all credit transactions
- Extracts transaction amounts
- Calculates final account balance
- Finds the first debit transaction
- Finds the index of a transaction with amount `10000`

This example helps understand array processing techniques in JavaScript.

## Variables Used

| Variable Name            | Description                                |
|---------------------------|--------------------------------------------|
| `transactions`            | Stores all transaction records             |
| `creditTransactions`      | Stores only credit transactions            |
| `transactionAmounts`      | Stores transaction amounts                 |
| `finalAccountBalance`     | Stores calculated account balance          |
| `firstDebitTransaction`   | Stores first debit transaction             |
| `transactionIndex`        | Stores index of amount `10000` transaction |
