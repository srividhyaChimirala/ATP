# JavaScript Object Update using Spread Operator

This program demonstrates how to copy and update objects using the JavaScript spread operator (`...`).

---

## Description

The program performs the following operations:

- Creates an original user object
- Copies the object using the spread operator
- Adds a new property (`age`)
- Displays both objects
- Keeps the original object unchanged
