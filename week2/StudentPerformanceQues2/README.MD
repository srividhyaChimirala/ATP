# JavaScript Student Performance Analyzer

This program demonstrates the use of important JavaScript array methods such as:

- `filter()`
- `map()`
- `reduce()`
- `find()`
- `findIndex()`

using a student performance example.

## Description

The program performs the following operations:

- Displays all student records
- Filters students who passed
- Adds grade fields to students
- Calculates average marks
- Finds student with `92` marks
- Finds index of student `"Kiran"`

This example helps understand array manipulation techniques in JavaScript.
