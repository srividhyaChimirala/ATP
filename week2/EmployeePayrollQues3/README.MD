# JavaScript Employee Management System

This program demonstrates the use of important JavaScript array methods such as:

- `filter()`
- `map()`
- `reduce()`
- `find()`
- `findIndex()`

using an employee management example.

---

## Description

The program performs the following operations:

- Displays all employee records
- Filters employees from the IT department
- Adds a 10% bonus to employee salaries
- Calculates total salary payout
- Finds employee with salary `30000`
- Finds index of employee named `"Neha"`

This example helps understand array manipulation techniques in JavaScript.
