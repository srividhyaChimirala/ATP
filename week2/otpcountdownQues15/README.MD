# JavaScript OTP Countdown Simulator using setInterval()

This program demonstrates how to create a countdown timer in JavaScript using the `setInterval()` function.

---

## Description

The program simulates an OTP (One-Time Password) countdown system.

It performs the following operations:

- Displays OTP sent confirmation
- Starts a countdown from 10 seconds
- Displays remaining seconds every second
- Stops the timer when countdown ends
- Displays "Resend OTP" message

This example helps understand repeated execution in JavaScript.
