# JavaScript Array Copying using Spread Operator

This program demonstrates how to copy and extend arrays using the JavaScript spread operator (`...`).

---

## Description

The program performs the following operations:

- Creates an original fruits array
- Creates an additional fruits array
- Copies both arrays using the spread operator
- Adds a new fruit (`orange`)
- Displays all arrays

The original array remains unchanged.
