# JavaScript Shopping Cart Analyzer

This program demonstrates the use of important JavaScript array methods such as:

- `filter()`
- `map()`
- `reduce()`
- `find()`
- `findIndex()`

using a shopping cart example.

## Description

The program performs the following operations:

- Displays all cart products
- Filters only in-stock products
- Creates a new array with product names and total prices
- Calculates grand total of all cart items
- Finds product named `"Mouse"`
- Finds index of product `"Keyboard"`

This example helps understand array manipulation techniques in JavaScript.

## Variables Used

| Variable Name      | Description                            |
|-------------------|----------------------------------------|
| `cart`            | Stores shopping cart products          |
| `inStockProducts` | Stores only available products         |
| `productSummary`  | Stores product name and total price    |
| `grandTotal`      | Stores total cost of all products      |
| `mouseProduct`    | Stores details of `"Mouse"` product    |
| `keyboardIndex`   | Stores index of `"Keyboard"` product   |
