# JavaScript Exam Portal Simulator using setTimeout()

This program demonstrates how asynchronous operations work in JavaScript using the `setTimeout()` function.

---

## Description

The program simulates a simple online exam portal workflow.

It performs the following operations:

- Displays exam submission message
- Waits for 2 seconds
- Displays answer evaluation message
- Waits for another 2 seconds
- Displays final result

This example helps understand delayed execution in JavaScript.
