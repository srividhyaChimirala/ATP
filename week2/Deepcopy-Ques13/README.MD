# JavaScript Deep Copy using structuredClone()

This program demonstrates how to create a deep copy of an object in JavaScript using the `structuredClone()` method.

---

## Description

The program performs the following operations:

- Creates an original `order` object
- Creates a deep copy of the object using `structuredClone()`
- Modifies nested properties in the copied object
- Updates:
  - Customer city
  - Product price
- Displays both original and copied objects
- Verifies that the original object remains unchanged

This demonstrates safe object cloning and data isolation in JavaScript.
