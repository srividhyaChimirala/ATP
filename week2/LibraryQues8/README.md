# Library Management System

This program demonstrates a simple Library Management System using JavaScript classes and objects.

## Description

The program creates a `Book` class and uses it to manage a collection of books in a library.

Each book contains:
- Title
- Author
- Number of pages
- Availability status

The program performs operations like:
- Borrowing books
- Returning books
- Displaying book details
- Checking long books
- Counting books with more than 300 pages
- Displaying available books

## Methods Used

### `borrow()`
Marks the book as borrowed.

### `returnBook()`
Marks the book as returned.

### `getInfo()`
Displays the title, author, and pages of the book.

### `isLongBook()`
Checks whether the book has more than 300 pages.
